# V-Phone Website

V-Phone is a smartphone company website developed as a Human Computer Interaction (HCI) course project.

The website is designed to showcase V-Phone smartphones based on different customer needs, including gaming performance, camera quality, and affordable pricing.

## Project Overview

The website consists of five main pages:

- Home
- Products
- Promotion
- About Us
- Register

The project focuses on creating a user-friendly and responsive interface with clear navigation and consistent visual design.

## Features

The website includes:

- Product showcase and recommendations.
- Product image slider on the Home page.
- Product categories for Gaming, Camera, and Budget smartphones.
- Product filtering functionality.
- Promotion and shopping information.
- Company information and contact details.
- Customer registration form with JavaScript validation.
- Responsive layout for desktop and mobile screens.

## UI/UX Design

The website prototype was first designed using Figma before being implemented into a functional website.

The design focuses on:

- Clear visual hierarchy.
- Consistent navigation.
- Simple and intuitive user interface.
- Responsive layout.
- Consistent colors, typography, and components.

## Technologies

- HTML
- CSS
- JavaScript
- Figma

## Project Files

- `index.html` - Home page.
- `products.html` - Product listing and filtering.
- `promotion.html` - Promotions and shopping benefits.
- `about.html` - Company information.
- `register.html` - Customer registration form.
- `CSS/` - Stylesheets for the website.
- `JS/` - JavaScript functionality.
- `ASSETS/` - Images and other website assets.

## Project Scope

This project focuses on frontend website development and HCI implementation. The website does not include backend functionality, database integration, or real transaction processing.
